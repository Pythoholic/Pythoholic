### 🧠 Aedis Gustle

An **AI-native technical interview platform** built around adaptive, realistic engineering interviews.

Instead of generating a fixed list of questions, Gustle uses the candidate's context to construct an interview experience around:

* Target role and job description
* Resume and engineering background
* Configurable difficulty
* Coding interviews
* System design
* Adaptive follow-up questions
* Agent-driven interview workflows
* Collaborative design sessions

The goal is to make an AI interview feel less like answering generated questions and more like working through a real technical interview.

---

### ☁️ ZoneSmith

A terminal-first **AI operator for Cloudflare infrastructure**.

ZoneSmith explores how AI can work alongside infrastructure engineers while keeping execution explicit and human-controlled.

Areas include:

* Infrastructure discovery
* Cloudflare resource inspection
* Configuration analysis
* Troubleshooting assistance
* Infrastructure change generation
* Terraform generation
* Change review
* Human-approved execution

---

### ⚡ AI Quick Gen · Prompt Engine

A structured prompt-generation and model-orchestration system for generative AI.

Rather than relying entirely on free-text prompting, the system works with curated knowledge, generation rules and model-specific profiles.

I’ve been exploring:

* Structured prompt generation
* Prompt knowledge bases
* Model-specific prompt profiles
* Constraint handling
* Prompt ranking
* Token budgeting
* Local and cloud AI providers
* Reproducible generation workflows

---

### 🔨 NyxForge · ForgeAI · ForgeBAT

A set of tools exploring **AI-assisted visual generation and controlled generation workflows**.

The broader system brings together models, providers, jobs, galleries, generation recipes and reusable configurations.

ForgeBAT focuses specifically on controlled batch generation:

* Generation recipes
* Fixed parameters
* Parameter pools
* Randomized parameters
* Deterministic planning
* Batch preview
* Job execution
* Result comparison
